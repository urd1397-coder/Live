# Live

AI streamer prototype project. شخصية عربية تروي السيناريو وتتفاعل معه حرفياً (تضحك، تصرخ، تفكر، تغضب…).

## Run locally

```
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

ثم افتح **http://localhost:8000** في المتصفح.
لا تفتح `frontend/index.html` مباشرة كملف: الصفحة تحمّل `/style.css` و`/app.js` من السيرفر، فبدونه تطلع صفحة بدون تصميم.

## كيف تتفاعل الشخصية

1. **فهم المعنى**: كل جملة تُحلَّل (كلمات، علامات `!` `؟` `…`، مدّ الحروف مثل «ياااا» و«هههه») ويتحدد انفعالها: يضحك، يصرخ، يتفاجأ، يغضب، يفكر، حزين، خايف، ساخر، متحمس.
2. **توجيه يدوي**: ضع قبل أي جملة `[يصرخ]` أو `(يضحك)` أو `*يفكر*` وتتفوق على التحليل التلقائي. التوجيهات لا تُقرأ بصوت عالٍ.
3. **الأداء**: الوجه (حواجب، عيون، فم) والجسم (يدين، رأس، قفز، اهتزاز) يتغيران قبل الجملة، والفم يتحرك مع الكلام، وتطلع أصوات تفاعل (صرخة، ضحكة، «ممم») ومؤثرات صوتية.
4. **الشخصية (rig)**: ملف `frontend/rig.js`. هيكل SVG بمفاصل مستقلة (رأس، سماعات، حواجب، عيون، فم، ذراع وساعد ويد) ومحرك حركة بزنبرك، مع تنفس ورمش ومزامنة فم. كل انفعال معرّف في `POSES` بقيم زوايا وتعابير، وتقدر تعدّلها أو تضيف انفعالاً جديداً بسطر واحد.
5. **خريطة التفاعل** تحت السيناريو تعرض الانفعال المكتشف لكل جملة، واضغط أي واحد لتجربته.

Prototype only: no game capture, TikTok chat connection, or voice cloning yet.
