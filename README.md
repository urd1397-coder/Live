# Live Studio

استوديو لصناعة فيديوهات يرويها مقدّم كرتوني عربي يتفاعل مع القصة (يتفاجأ، يخاف، يفكر، يضحك…).

## التشغيل محلياً

```
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

ثم افتح **http://localhost:8000**. لا تفتح `frontend/index.html` كملف مباشرة، لأن الصفحة تُحمَّل من السيرفر.

## الكاتب الذكي (حبكة قوية)

يعمل بثلاث مراحل منفصلة، وكل مرحلة قابلة للتعديل قبل التي بعدها:

1. **الحبكة**: بطل له رغبة وعيب، رهانات واضحة، تفاصيل تُزرع وتُحصد، منتصف يقلب الأمور، لحظة أسوأ، مفاجأة عادلة، وصورة أخيرة.
2. **السرد**: يحوّل الحبكة إلى مقاطع منطوقة باللهجة المختارة، ومع كل مقطع انفعال وشدة ووقفة.
3. **المحرر القاسي**: يفحص النص مقابل قائمة جودة، ويعيد كتابة الضعيف.

يحتاج مفتاحاً في متغيرات البيئة (على Render: Environment):

| المتغير | الغرض |
|---|---|
| `GEMINI_API_KEY` | **مجاني**: مفتاح Gemini من aistudio.google.com/apikey (الأولوية الأولى لو وُجد). النموذج `gemini-2.5-flash` مع بدائل تلقائية (`flash-lite`) وإعادة محاولة عند حد الاستخدام، ويكتشف النماذج المتاحة تلقائياً لو تغيّرت الأسماء. غيّره بـ `GEMINI_MODEL` |
| `ANTHROPIC_API_KEY` | مفتاح Claude (مدفوع). النموذج الافتراضي `claude-sonnet-5-5`، وغيّره بـ `ANTHROPIC_MODEL` |
| `OPENAI_API_KEY` | بديل. النموذج بـ `OPENAI_MODEL` |
| `LLM_PROVIDER` | اختياري: `gemini` أو `anthropic` أو `openai` لفرض مزوّد معيّن |

بدون مفتاح يبقى كل شيء يعمل عدا زرّي الكتابة والتحليل الذكي: تقدر تلصق نصاً جاهزاً وتحلله محلياً.

## تحليل النص

- **بالذكاء الاصطناعي** (`/api/analyze`): يفهم السياق والمفارقة ويحدد انفعال الراوي وشدته.
- **محلي**: يفهم النفي («ما خفت»)، ويقلّل التمثيل المتكرر، ويرفع المفاجأة بعد الهدوء.
- **توجيه يدوي** قبل أي جملة: `[يصرخ]` `[يضحك]` `[يفكر]` `[يتفاجأ]` `[يغضب]` `[حزين]` `[يخاف]` `[يسخر]` `[يتحمس]` `[جاد]`.

## الصوت

لا توجد أصوات «ها ها» أو «آآه» مصطنعة. الصوت طبيعي بتغيّر بسيط في الإيقاع، والتعبير من الوجه والجسم. الفم يتحرك مع شدة الصوت الفعلية.

الترتيب: **ElevenLabs** (`ELEVENLABS_API_KEY` + `ELEVENLABS_VOICE_ID`) ← **OpenAI TTS** (`TTS_PROVIDER=openai`) ← **edge-tts** (بدون مفتاح، أصوات عصبية عربية، يحتاج أن يصل الخادم للإنترنت) ← صوت المتصفح.

## المحرر

- مقاسات: 9:16، 16:9، 1:1، 4:5.
- خلفيات: جاهزة، لون، تدرّج، أو صورتك (مع تعتيم وضبابية). شاشة خضراء للدمج.
- نصوص على المسرح (سحب وتحريك)، وترجمة تلقائية للجملة الحالية مع تمييز كلمات.
- خط زمني: لكل مقطع انفعال وشدة ووقفة، مع تقسيم ونقل وتشغيل من أي مقطع.
- الحفظ التلقائي في المتصفح، و«حفظ/فتح» لملف `.livestudio.json`.

## تغيير الشخصية

من تبويب «الشخصية»:
- **المدمجة**: ألوان الوجه والخطوط والسماعة.
- **صورة / صور**: صورة واحدة تتحرك تلقائياً، أو صور لكل انفعال سمِّها `laugh.png` أو `ضحك.png` وارفعها دفعة واحدة. صورة `talk` اختيارية لفم مفتوح.
- **ملف SVG جاهز**: سمِّ المجموعات (`id` أو `data-live`): `head` `body` `arm-l` `arm-r` `mouth` (أو `mouth-open`) `eyes` و`face-<emotion>`. الأجزاء الناقصة تُتجاهل. نموذج في `frontend/characters/sample-rig.svg`.
- حزمة الشخصية قابلة للتصدير والاستيراد (`.livechar.json`).

## الأصوات واللغات (للاستخدام التجاري)

الموقع تجاري، لذلك الأصوات من مزوّد **مرخّص**: **Azure AI Speech** (`AZURE_SPEECH_KEY` + `AZURE_SPEECH_REGION`)، وفيه حصة مجانية شهرية. فيه 64 صوتاً بلهجات عربية كثيرة (سعودي، إماراتي، كويتي، قطري، بحريني، عماني، يمني، سوري، لبناني، أردني، عراقي، مصري، ليبي، تونسي، جزائري، مغربي) ولغات أخرى (إنجليزي، فرنسي، إسباني، ألماني، تركي، أردو، فارسي، هندي، إندونيسي، روسي، إيطالي، برتغالي، ياباني، كوري، صيني).
- بدائل: `ELEVENLABS_API_KEY` + `ELEVENLABS_VOICE_ID` (الترخيص التجاري يحتاج خطة مدفوعة)، أو `OPENAI_API_KEY` مع `TTS_PROVIDER=openai`، أو أصوات Gemini (8 أصوات، حصة مجانية يومية صغيرة) عند وجود `GEMINI_API_KEY`.
- **edge-tts أُزيل** لأنه يستعمل خدمة قراءة متصفح Edge بلا ترخيص تجاري.
- لكل مقطع صوت خاص من محرر المقطع، وزر «هذا الصوت من هنا للنهاية» لتغيير الصوت عند نقطة معيّنة.
- الأداء يتلوّن بالانفعال (سرعة وطبقة بتغيير بسيط)، وتُخزَّن المقاطع المتكررة مؤقتاً، ويبدأ توليد الصوت قبل المقطع بمقطعين.
- «🩺 فحص الصوت» في تبويب الصوت يشرح سبب أي فشل. صوت المتصفح احتياطي فقط ولا يدخل الفيديو المصدَّر.
- التحليل التلقائي للانفعالات مبني على العربية. للغات الأخرى استخدم وسوم المخرج مثل `[يصرخ]`.
- منصات النشر (تيك توك، يوتيوب) تطلب غالباً وسم المحتوى المُولَّد بالذكاء الاصطناعي.

## تصدير الفيديو

زر «🎬 تصدير فيديو» بجانب أزرار التشغيل: يرسم المسرح (الخلفية، الشخصية، المكتب، النصوص، الترجمة) على canvas ويسجّله أثناء تشغيل السرد، ثم ينزّل ملف MP4 أو WebM حسب المتصفح بمقاس المسرح المختار (540/720/1080 للضلع الأقصر).
- الصوت يدخل الفيديو فقط إذا كان صوت الخادم العصبي (تبويب الصوت). صوت المتصفح لا يمكن تسجيله، فيخرج الفيديو صامتاً مع تنبيه قبل البدء.
- أبقِ التبويب ظاهراً أثناء التسجيل (المتصفح يبطّئ الرسم في الخلفية). زر «إيقاف» يلغي التصدير.
- مجرّب فعلياً: 540×960، ~29 إطاراً/ث، فيديو + صوت، بدون لقطات فارغة.
